# Template Backlog

Templates reduce one-off custom code and make the skill faster.

## High Priority

- `create_flag_diagram.py`
  - Trigger: national flags, symbolic emblems, simple geometric marks.
  - Lesson: Brazil flag required custom geometry and validation; this should become reusable.

- `create_floorplan.py`
  - Trigger: airplane, building, room, venue, event layout.
  - Lesson: Boeing 747 floorplan was useful but hand-coded.

## Medium Priority

- `create_timeline.py`
  - Trigger: histories, roadmap, project milestones.

- `create_comparison_matrix.py`
  - Trigger: compare tools, vendors, plans, features, options.

- `create_concept_map.py`
  - Trigger: explain a topic with central node and related ideas.

## Rule

If a diagram family appears twice, build a template before the third request.
